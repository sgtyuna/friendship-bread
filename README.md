# Friendship Bread site

Public page for Kathleen's pay-what-you-can bread, Kingston, Tennessee.

- `index.html` is the page. It holds no words about the bread.
- `content/site.json` and `content/breads.json` hold every word and price. Change those, not the HTML.
- `content/site.json` → `form.provider` (`web3forms` or `formspree`) and `form.key` turn on the send-to-email box. Empty = the page falls back to copy-the-message and a mail link.

Hosted on GitHub Pages from the `main` branch.
